[定位]
    这份表帮你把用户的形容词翻成可执行的方向，也帮你在生成前认出「给任何页面都会给的默认」。锚点产品迭代快，用前 WebSearch 核当前公认做得好的，不照搬这里的名字。

[风格词汇]
    每种给：一句气质、适合什么、不适合什么、注意。用户点名时先追问「你要的是它哪一点」，只学一点，不整套抄。
    | 风格 | 气质 | 适合 | 不适合 | 注意 |
    |---|---|---|---|---|
    | 瑞士极简 / 编辑网格 | 严谨网格、大留白、克制字重、结构靠对齐 | 内容阅读、文档、品牌站、专业工具 | 需要强引导的消费流程 | 容易平庸，大胆要放一处 |
    | 数据密集工作台 | 32px 行高表格、发丝线分层、tabular-nums、状态点 | 仪表盘、后台、运维、金融 | 首次使用的消费者 | 密度由内容与受众定，不由品味定 |
    | 纸感 / E-ink | 暖纸底、单墨、明度即层级、无阴影 | 案头工具、审核、标注、文档 | 需要多色语义的实时监控 | 语义靠形状不靠颜色 |
    | OLED 深色工作区 | 近黑底、发丝线、极少彩色 | 开发工具、剪辑、长时间盯屏 | 户外强光下的操作端 | 纯黑刺眼，深色不是浅色反转，对比要单独测 |
    | 玻璃拟态 / Liquid Glass | 半透明层、折射与景深、材质感 | 系统级 chrome、首屏英雄区、媒体类 | 密集内容区、低端机、文字多的页面 | GPU 多吃 15-25%，对比难保，只用于 chrome 与英雄时刻，底层保持扁平 |
    | Material 3 Expressive | 动效 token、动态色、表现性形状 | Android 原生、消费 app | 桌面专业工具 | 动效有物理模型，不是加一堆过渡 |
    | 新野兽派 | 粗黑边、高对比、大字、生硬对齐 | 创意品牌、潮流、活动页 | 企业后台、金融 | 「丑得有意」需要极高控制力，否则就是丑 |
    | Bento 网格 | 模块化卡片、不等分网格 | 功能聚合页、营销站 | 长流程、表单 | 极易落入「SaaS 卡片套件」通病 |
    | 克莱 / 软 UI | 圆润体块、柔和阴影、可爱 | 儿童、教育、轻消费 | 专业工具 | 圆角大要有层级，不能一律 |
    | 极光 / 渐变网 | 一条彩色渐变当唯一强调 | AI 产品的 Agent 活动标识、品牌点睛 | 满屏渐变背景 | 渐变只给一个角色（比如只给 AI 的动作），不当背景 |
    | 终端 CLI | 等宽、ANSI 色、box-drawing、列宽 degrade | 命令行工具、编程 Agent | 消费者 | 80 列怎么塌要定 |
    | 空间 / VisionOS | 深度层、玻璃面板、超大圆角 | 头显、空间应用 | 平面 web | 不要在平面产品里模仿 |

[参考锚点对]
    每轴两个对立的真实产品，用前核当前版本：
    - 信息密度：Linear（紧凑）vs Notion（宽松）
    - 色彩温度：Stripe（冷）vs Airbnb（暖）
    - 正式程度：Bloomberg Terminal（严肃）vs Figma（活泼）
    - 视觉层次：Apple（极简大留白）vs Vercel Dashboard（密但干净）
    - 导航：Slack（侧栏）vs Spotify（底部 Tab）vs Raycast / Linear（命令面板优先）
    - 主题：GitHub（默认深）vs Google Docs（默认浅）
    - 圆角：iOS（大圆角柔和）vs Windows（直角锐利）
    - 插画：Dropbox（抽象插画）vs 无插画纯 UI
    - 开发者工具气质：Cursor（暖奶油编辑感 + 单一橙）vs Warp（深色终端 + 极光）
    - AI 产品：Claude / ChatGPT（对话 + 画布）vs Perplexity（引用优先）

[感受 → 属性补充]
    SKILL 的翻译表之外：
    - 「安静 / 沉稳」→ 低饱和、小字号差、慢而少的动效、无装饰性图形。
    - 「有生命 / 活着」→ 一处响应用户动作的动效（打开、展开、确认），不是每段淡入。
    - 「专业」→ 先问哪种：TED 讲者温和权威、Apple Keynote 神圣感、麦肯锡数据冷静。
    - 「像手写 / 有人味」→ 暖底、人文无衬线或衬线、不规则留白；不是手写字体。

[2026 趋势注记]
    只当校准，不当答案。
    - 表面：Apple Liquid Glass 与 Google Material 3 Expressive 收敛在「token 化、带物理模型、随上下文响应的表面」；实践上是「扁平地基 + 只在 chrome 与英雄时刻用玻璃 / 表现性动效」。
    - token：DTCG 格式、原始 → 语义 → 组件三层、按意图命名（`color-action-primary` 不是 `blue-500`）、无障碍约束写进 token；AI 与 MCP 工具直接消费 token，所以 DESIGN.md 是给机器读的。
    - 无障碍：欧盟无障碍法案已生效，AA 是地板不是加分。
    - Agent 产品：非线性流程、自主性是一个可调的旋钮、审批只在不可逆处、AI 活动有专属视觉语言（见 agent-ux-patterns.md）。
    - 字体：一到两个字族，避免所有人都在用的默认（Inter 当正文没问题，但当「个性」就是没个性）。

[AI 生成界面的通病]
    这些是默认不是选择，出现在任何题材上。brief 钉死了的照 brief；没钉死的轴不许落在这上面。生成后逐条对照，命中就说出改了什么。
    五类聚簇：
    1. 奶油底（近 #F4F1EA）+ 高对比衬线大标题 + 陶土 / 暖泥橙强调（近 #D97757）。
    2. 近黑底 + 单一酸绿或朱红强调。
    3. 报纸式：发丝线、零圆角、密栏。
    4. SaaS 卡片套件：内容切成一样圆角的卡、一律同一个圆角、一律同一层灰影、渐变当装饰。
    5. 模板装饰：每个标题上方一条字距拉开的 ALL-CAPS 眉标；元信息用中点串「A · B · C」；「WORD — 片段」带空格的破折号标签；#0B0B0B / #111 冒充黑；小数据标签用等宽；链接与按钮尾巴加「→」。
    排版通病：只把标题里一个词换色或斜体；标签全大写；内容上方多余的说明标签；数字编号 01 / 02 / 03 用在不是序列的内容上。
    动效通病：每段淡入上滑、每张卡悬停过渡；只留一处编排好的时刻，其余只响应用户动作。
    布局通病：过度居中、紫色渐变、一律圆角、Inter 当个性。
    首屏通病：大数字 + 小标签 + 支撑统计 + 渐变强调——只有它真是最好的选择才用；先问这个产品世界里最有特征的东西是什么。

[质量地板不宣告地做到]
    响应到移动端、焦点可见、reduced-motion 生效、对比达 AA、色彩和谐、行长 <80 字符（中文约 40 字）、按钮说清结果、错误说清下一步。细则见 ui-quality-floor.md。
