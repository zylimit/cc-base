# 展示页只放实际数据，推断标注不上交付物

**问题描述**：做 T6497 机房 OLT→ODF→首盒物理链路分析展示（data/build_t6497_guide.py 生成 data/t6497_connection_guide.html）时，发现 DigiFiber 导出数据没有记录 OSU 设备内部连接（板卡1↔板卡2），却把"板卡1→板卡2 同号口直通"的推断标注写到了展示图上。用户连续三条指示纠正：①"如果没有就不写了" ②"不要自己加戏" ③"一定要实际有的数据放上来"。

**触发场景**：数据展示/分析呈现类交付物（HTML 报告、链路图、可视化页面），数据源存在缺口、AI 想用推断补齐展示完整性时。

**教训/建议**：
- 交付物页面上只许放数据源里实际存在的记录；推断、推测、演绎性标注一律不上展示页，无论标注得多清楚是"推断"。
- 数据缺口就如实留空或标"无数据"，不拿推断冒充事实填坑。
- 推断最多在对话里口头说明依据（"数据没有记录 X，我推测是 Y，理由是 Z"），让用户自己判断，不能落到交付物上。
- 生成展示代码（如 build_*.py）时，凡是要渲染到页面上的字段，先确认它在数据源里真实存在；不存在就不渲染，不补演绎内容。
